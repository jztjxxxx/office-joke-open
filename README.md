One line of office comedy for make.fun's Office Joke Open: a joke about the standup meeting that went async and somehow got slower. The joke lives in `entry.txt` (and in `main.ts`); running the program writes it, unchanged, to `/output/entry.txt` for the make.fun judge.

## The joke

> Our standup is now async, which is corporate for: we still have the meeting, we just type it slower.

100 characters, one line — comfortably inside the contest's 200-character gate.

## Run it

```sh
node main.ts
```
